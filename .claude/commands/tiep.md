1. Đọc `docs/STATUS.md` (nhất là "Đang làm" và "Đang học"), plan đang làm trong `docs/plans/`, và `docs/learning/progress.md`.
2. Chạy `git status` và `git log --oneline -5` để xem code đang dở chưa commit, đối chiếu với "Bước đã xong" trong STATUS. Lệch nhau thì tin git và nói rõ.
3. Tóm tắt cho Liam trong 5–8 dòng: đang ở phase nào, task nào, mục 🎓 nào, bước nào đã xong, câu hỏi nào còn treo.
4. Nhắc lại ngắn kiến thức của bước trước (2–3 câu) để nối mạch, rồi hỏi một câu "Tự kiểm" liên quan nếu có.
5. Nêu **bước tiếp theo**: cần viết gì, ở file nào. Chờ Liam code theo Chế độ dạy trong `CLAUDE.md`.
6. STATUS trống hoặc không có gì đang dở thì chạy theo `/next`.
